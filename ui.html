Overwrite Existing Descriptions?

Some selected variables already have descriptions. Do you want to overwrite them?

Help
What this plugin does

Batch view, set, or clear descriptions on Figma variables across one or more collections — far faster than editing each variable individually in the Figma Variables panel.

Before you start

The plugin loads all variable collections in the current file. Use the filter checkbox to narrow the list to variables that already have descriptions, which is useful when you want to audit or clear existing copy.

How to use it

1. Optionally tick "Show only variables with descriptions" to filter the list.

2. Select variables using the collection-level checkbox (selects all in that collection) or individual row checkboxes. Use Select All at the top to select everything visible.

3. In the Action section, choose either "Clear all descriptions" or "Set description to:" and type your new description text in the field below.

4. Click Apply Changes. If any selected variables already have descriptions and you chose Set, a confirmation dialog asks whether to overwrite them — click Proceed to continue or Cancel to go back.

Understanding the output

A success or error banner appears briefly after the operation. The variable list refreshes automatically. Descriptions are written directly to the Figma file — there is no staging or preview step for description edits.

About

Variable Descriptions Manager — batch-edit variable descriptions across all collections in the current Figma file.
