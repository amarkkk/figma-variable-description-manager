# Changelog

All notable changes to Variable Descriptions Manager are documented in this file.

---

## [1.0.0] - 2025-11-17

### Initial Release

- Bulk clear or set descriptions for multiple variables at once
- Collection-based organization with variable grouping
- Smart filtering (show only variables with existing descriptions)
- Flexible selection (individual, collection-level, or select all)
- Overwrite protection with confirmation prompt
- Resizable window with size persistence
- Dark/Light theme toggle with preference persistence
